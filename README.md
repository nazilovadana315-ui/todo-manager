# To-Do Manager

## Жобаның мақсаты
Python тілінде тапсырмаларды басқаруға арналған консольдік бағдарлама жасау.

## Негізгі мүмкіндіктер
- Тапсырма қосу
- Тапсырмалар тізімін көру
- Тапсырманы орындалды деп белгілеу
- Тапсырманы жою

## Қолданылатын технологиялар
- Python
- Git
- GitHub
- Trello

## Команда
- Қатысушы 1 — Product Owner, әзірлеуші
- Қатысушы 2 — Scrum Master, әзірлеуші және тестілеуші

## Іске қосу
`python main.py`
Первая версия проекта подготовлена.
